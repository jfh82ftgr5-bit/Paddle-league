Paddle League Update

New:
- Full league roster with clickable player profiles
- Player stats: ELO, rank, W-L, win %, streak, point differential
- 1s / 2s / 3s records
- Player match history
- 1v1, 2v2, 3v3 match setup
- Team-based ELO using average team rating
- League match history shows teams and match style

The Supabase database migration for these features has already been applied.
Replace the existing files in your GitHub paddle-league2 repo with these, then Vercel will redeploy automatically.
