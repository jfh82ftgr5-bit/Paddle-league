Paddle League — Casual Play Update

New:
- Matches tab now has Ranked and Casual modes
- Ranked keeps match codes, confirmation, ELO, ranks, and official ranked history
- Casual uses match codes + opponent confirmation but never changes ELO or rank
- Casual supports 1v1, 2v2, and 3v3
- Casual matches can attach the selected court
- Casual results have their own history
- Player profiles show separate Casual Played, Casual Record, and Casual Win Rate
- Casual results appear in the Home activity feed with a CASUAL label

The Supabase casual-play database tables/functions have already been added.
